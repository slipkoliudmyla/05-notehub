# NoteHub

Навчальний застосунок на React і TypeScript для роботи з особистою колекцією нотаток через NoteHub API.

TanStack Query отримує нотатки та кешує дані за пошуковим запитом і номером сторінки. На сторінці відображаються 12 нотаток, а React Paginate перемикає сторінки. Контрольоване поле пошуку оновлює запит через 300 мс після завершення введення та повертає користувача на першу сторінку.

Нова нотатка створюється у модальному вікні через Formik-форму. Yup перевіряє заголовок від 3 до 50 символів, контент до 500 символів та обов'язковий тег із доступного списку. Модальне вікно закривається через Cancel, Escape або клік на фон.

Створення й видалення виконуються через мутації TanStack Query. Після успішних змін кеш нотаток оновлюється. Після видалення останньої нотатки на сторінці відкривається попередня сторінка. Помилка збереження залишається видимою у формі та дозволяє повторити спробу зі збереженими значеннями полів.

## Запуск

Потрібні Node.js 24 або новіша версія та npm. Отримайте персональний токен у документації NoteHub API та додайте його до змінної середовища Vite `VITE_NOTEHUB_TOKEN`.

```bash
npm ci
npm run dev
```

## Перевірка та збірка

```bash
npm run lint
npm run format:check
npm run build
```

Для Vercel використовується команда збірки `npm run build`, каталог результату `dist` та змінна середовища `VITE_NOTEHUB_TOKEN`.
